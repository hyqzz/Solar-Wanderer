# 社区规则

## Solar Wanderer · 遨游太阳系 社区行为准则

### 我们的目标

创建一个友善、开放、有营养的社区，让每个对太空、科学、技术感兴趣的人都能交流、学习和贡献。

### 必须遵守

1. **尊重他人**
   - 不人身攻击、不嘲讽、不歧视。
   - 对新成员保持耐心。

2. **保持相关**
   - 讨论围绕 Solar Wanderer、天文、航天、WebGL/Three.js、教育应用。
   - 避免无关政治、宗教、商业广告。

3. **分享有价值的内容**
   - 截图/视频请尽量注明拍摄地点和参数。
   - 提问时说明设备、浏览器、复现步骤。
   - 反馈 bug 欢迎附截图或录屏。

4. **保护隐私**
   - 不要公开他人隐私信息。
   - 不要在群里发账号密码或 API key。

5. **遵守法律**
   - 禁止分享违法、盗版、侵权内容。
   - 禁止 spam、机器人刷量。

### 鼓励做的事

- 分享你最喜欢的探索画面。
- 帮助回答新成员的问题。
- 给 GitHub 项目点 star、提 issue、提交 PR。
- 把项目推荐给老师、学生、天文爱好者。
- 提出有建设性的产品建议。

### 不鼓励的事

- 只发链接不说话。
- 重复发送相同内容。
- 过度自吹自擂。
- 在群里私下交易。

### 违规处理

- 第一次：管理员警告。
- 第二次：禁言 24 小时。
- 第三次：移出群聊/社区。

### 管理员职责

- 维持讨论秩序。
- 及时处理违规。
- 定期汇总反馈给开发团队。
- 组织活动和答疑。

## 英文版

### Solar Wanderer Community Code of Conduct

**Be respectful.** No harassment, discrimination, or personal attacks.

**Stay on topic.** Solar Wanderer, astronomy, space, WebGL/Three.js, education.

**Share value.** Screenshots with context, bug reports with details, questions with setup info.

**Protect privacy.** No doxxing, no sharing credentials.

**Follow the law.** No illegal, pirated, or infringing content. No spam.

**Violations:** warning → temporary mute → removal.
