# Day 4: 短视频 Batch 1 — 尺度震撼类

## 今日目标

发布 5 条以“尺度”为主题的短视频，制造视觉冲击。

## 发布平台

- 抖音
- 小红书
- B站（Shorts）
- YouTube Shorts
- TikTok
- Twitter/X

---

## 通用制作规范

- **长度**：15–30 秒
- **比例**：9:16 竖屏为主，B站/YouTube 可发 16:9 横屏版
- **音乐**：史诗感/太空感，渐进式
- **字幕**：大字，底部 1/3，简洁有力
- **结尾**：固定显示 `sw.icodestar.net` 和 `免费 · 开源 · 浏览器即玩`
- **开场**：前 3 秒必须震撼

## 5 条视频脚本

### 视频 1：从地球缩放到奥尔特云

**标题**：从地球缩到太阳系边缘，需要多久？

**分镜**：
- 00:00–00:03：地球海面特写
- 00:03–00:08：快速后退，看到月球、火星、木星、土星
- 00:08–00:12：继续后退，行星变成小点
- 00:12–00:17：到达奥尔特云，回望太阳系
- 00:17–00:20：CTA

**字幕**：
- "这是地球。"
- "这是火星。"
- "这是木星。"
- "这是太阳系。"
- "这只是它的一小部分。"

### 视频 3：土星环有多薄

**标题**：土星环薄到难以置信

- 00:08–00:13：显示环几乎薄成一条线

- 00:18–00:20：CTA

- "但厚度只有 10–20 米。"
- "按比例，比纸还薄。"
