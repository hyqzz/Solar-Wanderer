## 通用评论区回复话术

### 中文
- “这是游戏吗？” → 不是游戏，是浏览器里的实时太阳系模拟器，打开即玩。
- “数据真实吗？” → 行星/月球位置基于 NASA JPL Horizons 星历，真实比例 1:1。
- “手机能玩吗？” → 可以，但推荐用性能较好的手机或桌面端。
- “开源吗？” → MIT 开源：github.com/hyqzz/Solar-Wanderer

### English
- “Is this a game?” → It’s a real-time solar system simulator, not a game. Runs in the browser.
- “Is the data real?” → Planets and moons use NASA JPL ephemerides; scale is 1:1.
- “Does it work on mobile?” → Yes, but desktop / newer phones give the best experience.
- “Open source?” → MIT: github.com/hyqzz/Solar-Wanderer
