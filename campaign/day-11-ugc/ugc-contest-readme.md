# UGC 活动规则

## 活动名称

#我在太阳系的第一张照片 / #MyFirstSolarWandererShot

## 活动时间

长期有效，每周评选一次，每月公布月度冠军。

## 参与方式

1. 打开 https://sw.icodestar.net
2. 探索任意天体或轨道视角
3. 截图或录屏（推荐 1080p 以上）
4. 在社交平台发布，带话题 #SolarWanderer #遨游太阳系
5. 把链接发到 Discord #showcase 或微信群

## 内容要求

- 必须是 Solar Wanderer 内的画面。
- 允许轻微调色，但不允许替换天体/伪造数据。
- 请注明拍摄地点（如“月球表面看地球升起”）。
- 鼓励配上你的感受或科普小知识。

## 评选标准

- 视觉冲击力（40%）
- 科学/教育价值（30%）
- 创意和故事（30%）

## 奖励

- 每周精选：官方账号转发 + 官网展示
- 月度冠军：GitHub README 鸣谢 + 电子证书
- 年度大奖：项目定制周边（如未来有）

## 授权

参与即表示你允许 Solar Wanderer 项目在官网、README、社交媒体和宣传材料中使用你的作品，并会署名。

## 违规

- 严禁色情、暴力、政治内容。
- 严禁盗用他人作品。
- 违规者取消资格。
