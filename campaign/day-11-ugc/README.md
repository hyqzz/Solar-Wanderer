## UGC 活动主题

**主题：** #我在太阳系的第一张照片

**玩法：**
1. 打开 https://sw.icodestar.net
2. 飞到任意天体，拍下你最喜欢的画面
3. 发布到 Twitter/X / 微博 / B站 / 小红书
4. 带上话题 #SolarWanderer #遨游太阳系
5. 每周评选最佳，送上 GitHub README 展示位
