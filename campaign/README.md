## 如何使用本文件夹

1. 每天打开 `day-XX-xxx/` 文件夹。
2. 阅读该文件夹下的 `README.md`，了解当天目标。
3. 按顺序发布每个文件中的内容。
4. 发布完成后，在 `README.md` 里打勾或记录效果。

**原则：不要一天做完全部。按天执行，制造持续声量。**

## 注意事项

1. **不要复制粘贴同一段文案到多个平台**。每个平台调性不同，文件夹里已经做了适配。
2. **真诚互动**。回复评论比发帖子更重要。
3. **不要购买点赞/刷量**。会损害长期信任。
4. **截图和视频是核心资产**。宁可少发文字，也要多发画面。
5. **保留所有发布链接**。Day 12 要分析数据。
