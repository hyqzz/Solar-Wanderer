# Week 2 Milestone Goals

## Week 2 end-state

By the end of Day 21, the project should feel like it has momentum beyond the initial launch spike.

## Targets

| Category | Metric | Target |
|----------|--------|--------|
| Traffic | Weekly active users | ≥5,000 |
| Traffic | Returning user rate | ≥35% |
| GitHub | Total stars | ≥1,000 |
| GitHub | Forks | ≥80 |
| GitHub | Open issues (good first) | ≥5 |
| GitHub | Contributors | ≥5 |
| Social | Total followers across platforms | ≥2,000 |
| Social | Engagements (likes/shares/comments) | ≥2,000 |
| UGC | User screenshots/videos submitted | ≥50 |
| Education | Schools/teachers reached | ≥20 |
| Education | Demo sessions scheduled | ≥3 |
| Content | New pieces published | ≥15 |
| Product | Critical bugs fixed | ≥3 |
| Product | New feature shipped | ≥1 |

## Success signals

- People start mentioning Solar Wanderer without you posting first.
- GitHub issues include feature requests from real users.
- At least one educator asks for a classroom demo.
- At least one developer opens a PR.
- A KOL or media outlet agrees to cover it.

## Failure signals

- Traffic drops to <10% of launch day by Day 21.
- No new GitHub stars for 3 days straight.
- No UGC submissions.
- No replies from outreach.

## If failing, pivot to

1. **Niche focus:** target educators and astronomy clubs instead of broad tech.
2. **Content quality:** produce one truly exceptional video instead of many posts.
3. **Paid test:** small Reddit/Twitter ad spend to validate messaging.
4. **Partnership:** co-create with an established space account.

## Day 21 checklist

- [ ] Week 2 data reviewed
- [ ] Week 3 calendar drafted
- [ ] Top 3 user feedback turned into issues
- [ ] Thank-you post published
- [ ] Community AMA completed
- [ ] At least 1 PR merged
- [ ] Newsletter issue #1 sent (if applicable)

## Long-term milestones (30/60/90 days)

| Days | Milestone |
|------|-----------|
| 30 | 5,000 GitHub stars, 10,000 WAU, 10 contributors |
| 60 | First media mention, first school pilot, Discord 500 members |
| 90 | Stable organic traffic, 15,000 stars, 25 contributors, i18n expansion |

## 中文总结

第二周目标：把第一周的发酵转化为持续增长。重点是留存、内容再利用、深度合作和产品迭代。如果第二周结束时能达到 5,000 WAU、1,000 GitHub stars、5 位贡献者，就说明项目已经从“一次性发布”变成了“可持续产品”。
