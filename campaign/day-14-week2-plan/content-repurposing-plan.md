# Content Repurposing Plan

## Core idea

把第一周产出的 1 个 demo 视频、5 张截图、2 篇博客，变成 30+ 条跨平台内容。

## Source assets

| Asset | Count | Platforms |
|-------|-------|-----------|
| Main demo video (60s) | 1 | YouTube, Bilibili, Twitter/X, Weibo, Xiaohongshu, Douyin |
| Screenshots | 5+ | Twitter/X, Weibo, Xiaohongshu, Instagram, B站动态 |
| Technical blog | 2 | Dev.to, Medium, 掘金, 知乎专栏, 公众号 |
| Product Hunt post | 1 | Twitter/X thread, Reddit, LinkedIn |
| User quotes/stories | 3+ | Twitter/X, 微博, 小红书, Discord |

## Repurposing map

### Demo video

- 剪成 5 条 15s 短视频（每个平台一条）。
- 剪成 3 条 30s 带字幕版本。
- 提取 10 张静帧做图片帖。
- 生成 GIF 动图。
- 转成无音乐版本方便 TikTok/抖音二次配音。

### Screenshots

- 每张图 + 一句话科普 = Twitter/X 帖。
- 每张图 + 情绪文案 = 小红书/微博帖。
- 5 张图拼成长图 = 朋友圈/公众号。
- 加动态缩放效果 = 短视频。

### Technical blog

- 拆成 5 条 Twitter thread。
- 改成 1 篇知乎回答。
- 改成 1 篇掘金文章。
- 改成 1 个 B站专栏。
- 改成 1 个公众号图文。

### Product Hunt launch

- 成功/失败经验写成独立文章。
- 做成 "How I launched" thread。
- 截取评论做成感谢帖。

### User stories

- 做成图文卡片。
- 做成短视频口述。
- 做成 "Why they love it" 合集。

---

## Weekly repurposing schedule

| Day | Action |
|-----|--------|
| Mon | 从上周内容选 1 个核心素材 |
| Tue | 改成 3 个不同长度的版本 |
| Wed | 分发到 3 个平台 |
| Thu | 把评论/反馈做成新内容 |
| Fri | 汇总成 newsletter / 周总结 |

## 中文内容再利用示例

**原素材：** 火星蓝色日落截图

- 微博："在火星上看日落，天空是蓝色的。 because 尘埃散射蓝光。截图来自遨游太阳系 → link"
- 小红书："99% 的人不知道，火星日落是蓝色的" + 图 + 科普短句
- B站动态："火星蓝色日落原理，30 秒看懂" + 短视频
- 知乎回答："火星日落为什么是蓝色的？" + 截图 + 项目链接
- 公众号："我们在火星上拍到了蓝色日落" + 长文
