## Type labels

- Creator — KOL / 博主
- Educator — 教师 / 教育工作者
- Developer — 开发者 / 潜在贡献者
- Media — 媒体 / 记者
- User — 普通用户 / 粉丝
- Investor — 投资人（未来）

## Status labels

- New — 新联系人
- Replied — 已回复
- Interested — 有意向
- Committed — 已答应合作/分享
- Published — 已发布
- No reply — 未回复
- Nurture — 长期维护
- Passed — 暂时不跟进

## Follow-up rules

- 新联系 3 天内首次跟进。
- 有意向者每周维护一次。
- 每次互动后记下关键信息（兴趣点、孩子、学校、项目偏好）。
- 重要关系人在节假日前发一句问候。
